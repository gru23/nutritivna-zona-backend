# Nutritivna Zona Backend

Ovo je **Spring backend aplikacija** koja predstavlja serversku stranu sistema *Nutritivna Zona*.  
Aplikacija je posebno implementirana da podrži funkcionalnosti vezane za rad sa podacima nutricioniste i/ili korisnika sistema.

---

## 🧠 Opis

Backend servis:

- pruža **REST API** za frontend klijente,
- obrađuje poslovnu logiku aplikacije,
- komunicira s bazom podataka koristeći Spring Boot framework,
- odgovoran je za autentikaciju, autorizaciju i CRUD operacije. :contentReference[oaicite:2]{index=2}

Ovaj repo sadrži samo backend dio sistema — frontend (ako postoji) je zaseban projekat.

---

## 🛠️ Tehnologije

Projekt koristi:

- Java  
- Spring Boot  
- Maven  
- Docker (opcionalno, ovisno o konfiguraciji) :contentReference[oaicite:3]{index=3}
